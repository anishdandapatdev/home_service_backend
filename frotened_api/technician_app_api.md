# 🔧 Technician App — API Reference
> For Flutter Developer | All endpoints the Technician App will call

**Base URL (Local):** `http://localhost:3000/api/v1`
**Base URL (Production):** `https://your-app.railway.app/api/v1`

**Auth Header (required for all protected routes):**
```
Authorization: Bearer <access_token>
```

---

## 1. 🔐 Technician Login

Technicians do NOT use OTP. They use a phone + password login issued by the Admin.

### 1.1 Login
```
POST /auth/technician/login
```
**No auth required**

**Request Body:**
```json
{
  "phone": "9876543210",
  "password": "TechPassword123!"
}
```
**Response:**
```json
{
  "technician": {
    "id": "uuid",
    "name": "Rajesh Kumar",
    "phone": "9876543210",
    "kyc_status": "VERIFIED",
    "skills": ["ELECTRICAL", "FAN", "AC"],
    "service_area": ["721602", "Haldia"]
  },
  "access_token": "eyJhbGci...",
  "refresh_token": "eyJhbGci...",
  "expires_in": 900
}
```
> 💾 Save `access_token` in Flutter `SharedPreferences`

---

### 1.2 Refresh Token
```
POST /auth/refresh
```
**No auth required**

**Request Body:**
```json
{ "refresh_token": "eyJhbGci..." }
```

## 3. 🚀 Job Execution Flow

This is the step-by-step process for a technician to complete a job:

```
ASSIGNED → IN_PROGRESS → (photos + spare parts) → COMPLETED
```

---

### Step 1 — Mark Job as Started
```
PATCH /technician/jobs/:jobId/start
```
**Auth required**

**No request body needed**

**Response:**
```json
{
  "id": "uuid",
  "status": "IN_PROGRESS",
  ...
}
```

---

### Step 2 — Upload Before/After Photos

First, upload photo to S3, get the URL back:
```
POST /upload/file
```
**Auth required** | Content-Type: `multipart/form-data`

**Form fields:**
```
file: <image file>
folder: "job-photos"
```
**Response:**
```json
{ "url": "https://s3.amazonaws.com/job-photos/1234-photo.jpg" }
```

Then save the photo URLs to the job:
```
POST /technician/jobs/:jobId/photos
```
**Auth required**

**Request Body:**
```json
{
  "before_photos": ["https://s3.amazonaws.com/job-photos/before-1.jpg"],
  "after_photos": ["https://s3.amazonaws.com/job-photos/after-1.jpg"]
}
```

---

### Step 3 — Log Spare Parts Used (if any)
```
POST /technician/jobs/:jobId/spare-parts
```
**Auth required**

**Request Body:**
```json
{
  "name": "Ceiling Fan Capacitor 2.5μF",
  "cost": 180,
  "quantity": 1
}
```
**Response:**
```json
{
  "id": "part-uuid",
  "name": "Ceiling Fan Capacitor 2.5μF",
  "cost": 180,
  "quantity": 1,
  "approval_status": "PENDING"
}
```
> The customer will be notified to approve/reject this in their app.
> You can call this endpoint multiple times to add multiple parts.

---

### Step 4 — Complete Job with Customer Signature

⚠️ **IMPORTANT:** The job CANNOT be marked complete without a customer digital signature URL.

First upload the signature image:
```
POST /upload/file
```
**Form fields:**
```
file: <signature image>
folder: "signatures"
```
**Response:** `{ "url": "https://s3.amazonaws.com/.../signature.png" }`

Then complete the job:
```
POST /technician/jobs/:jobId/complete
```
**Auth required**

**Request Body:**
```json
{
  "customer_signature_url": "https://s3.amazonaws.com/signatures/sig-1234.png"
}
```
**Response:**
```json
{
  "job": { "id": "uuid", "status": "COMPLETED", "completed_at": "..." },
  "message": "Job completed cleanly and digital signature recorded. Invoice generated."
}
```
> Invoice is automatically generated by the backend after this call.

## 💡 Flutter Code Snippet (Technician App Dio Setup)

```dart
import 'package:dio/dio.dart';
import 'package:shared_preferences/shared_preferences.dart';

class TechnicianApiService {
  static const String baseUrl = 'https://your-app.railway.app/api/v1';
  final Dio _dio = Dio(BaseOptions(baseUrl: baseUrl));

  TechnicianApiService() {
    _dio.interceptors.add(InterceptorsWrapper(
      onRequest: (options, handler) async {
        final prefs = await SharedPreferences.getInstance();
        final token = prefs.getString('tech_access_token');
        if (token != null) {
          options.headers['Authorization'] = 'Bearer $token';
        }
        handler.next(options);
      },
    ));
  }

  // Login
  Future<Map> login(String phone, String password) async {
    final res = await _dio.post('/auth/technician/login',
        data: {'phone': phone, 'password': password});
    final prefs = await SharedPreferences.getInstance();
    await prefs.setString('tech_access_token', res.data['access_token']);
    return res.data;
  }

  // Get assigned jobs
  Future<List> getJobs() async {
    final res = await _dio.get('/technician/jobs');
    return res.data;
  }

  // Start a job
  Future<Map> startJob(String jobId) async {
    final res = await _dio.patch('/technician/jobs/$jobId/start');
    return res.data;
  }

  // Log spare part
  Future<Map> logSparePart(String jobId, String name, double cost, int qty) async {
    final res = await _dio.post('/technician/jobs/$jobId/spare-parts',
        data: {'name': name, 'cost': cost, 'quantity': qty});
    return res.data;
  }

  // Complete job
  Future<Map> completeJob(String jobId, String signatureUrl) async {
    final res = await _dio.post('/technician/jobs/$jobId/complete',
        data: {'customer_signature_url': signatureUrl});
    return res.data;
  }
}
```
